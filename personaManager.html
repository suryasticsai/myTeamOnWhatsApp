How to Use

  1. Add Persona: Click "Add Persona" or use "Auto-Create Sample".
  2. RAGina Auto-fill: Paste a bio in the modal and click "✨ Auto-fill" to extract fields automatically.
  3. Batch Import: Paste multiple bios (one per line) to generate all at once.
  4. Edit / Clone / Delete: Each card has action buttons.
  5. Export / Import: Download or upload your collection as JSON.
  6. GitHub Sync: Sign in with GitHub. Once authenticated, click "☁️ Push to GitHub" to commit persona.json directly to suryasticsai/myTeamOnWhatsApp. Every save also auto-pushes if you're logged in.
  7. Preferences: Toggle dark mode, theme color, and sounds via ⚙️.
